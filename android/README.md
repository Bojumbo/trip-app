# Trip Tracker — Android-трекер

Легкий застосунок для водія: **1 Activity + 1 foreground service**, без WebView,
без зовнішніх бібліотек крім `play-services-location`. APK ≈ 2–3 МБ.

## Що робить

- Ведде трек рейсу у фоні (foreground service типу `location`, постійна нотифікація).
- Виявляє зупинку: зміщення < 50 м за N хвилин (поріг задається, за замовчуванням 3).
- Питає «Це пауза?» і **запитує одометр у момент зупинки** — водій стоїть і бачить панель.
- Після підтвердження пише запис «Пауза» зі `source: auto`.
- Коли авто поїхало (>15 км/г протягом хв): запис «Продовження руху».
- Під час паузи будь-яке переміщення вважається ходьбою → окремий сегмент `walk`.
- Маршрут збирається сегментами (`drive` / `walk` / `still` / `nosignal`) і надсилається
  батчами по 20, з чергою на диск і ідемпотентністю за `client_uuid`.
- GPS-сенсор вимикається, коли немає відкритого рейсу — не гріє батарею даремно.

## Як підключити

1. У веб-застосунку створіть пристрій (буде в PWA) і скопіюйте токен.
2. У застосунку вкажіть адресу сервера (`https://…`), токен та назву.
3. Натисніть «Дозволити фон і сповіщення», потім «Увімкнути трекінг».
4. Позначте цей телефон активним трекером — інакше два телефони дадуть подвійні записи.

## Збірка

Локально потрібен **JDK 17** (на відміну від AGP 8). Збірка в CI:

```bash
git push        # спрацює .github/workflows/android.yml
```

APK з'явиться в **Actions → Build Android APK → Artifacts → trip-tracker-apk**.
Її встановлюють на телефон (дозволити встановлення з невідомих джерел).

- Debug-підпис достатній для власного використання, але **оновлювати можна лише
  тим самим підписом**. Якщо потрібен release — створіть `android/keystore/tracker.jks`
  і додайте `signingConfigs` у `app/build.gradle.kts`.
- Пароль keystore в GitHub: `Settings → Secrets → Actions`.

## Що відомо як обмеження

- На iPhone фон недосяжний — там лишається PWA (запис вручну).
- Якщо телефон залишається в кабіні, пішохідний трек не з'явиться (немає даних).
- Blackbox-оставка: якщо водій не відповів на діалоз, запис не створиться.

## Ключові файли

| Файл | Призначення |
|------|-------------|
| `TrackerService.kt` | Сервіс: стан-машина, детекція зупинки, сегменти, відправка |
| `MainActivity.kt` | Налаштування, діалог «Це пауза?», дозволи |
| `ApiClient.kt` | HttpURLConnection + Bearer-токен |
| `Polyline.kt` | Кодування маршруту в Google polyline |
| `Prefs.kt` | Налаштування в SharedPreferences |
| `IsoDate.kt` | Дата/час у форматі `YYYY-MM-DD` / `HH:MM` |

# DECISIONS.md — журнал рішень

> Тільки дописування **зверху**. Нічого не видаляємо.
> Застаріле позначаємо `❌ скасовано` і залишаємо на місці — щоб через місяць було видно, чому передумали.

| Дата | Рішення | Причина | Альтернативи, які відкинули |
|------|---------|---------|------------------------------|
| 2026-10-17 | UI маршруту: MapLibre GL JS + `pmtiles`-протокол, обидва в `public/vendor/` | Рендерити полілінії, курсор, зум і підказки самотужки — це велосипед на 500+ рядків; локальні файли не ламають CSP | Свій SVG/Canvas-рендер (повний контроль, але багато коду й немає підкладки) |
| 2026-10-17 | Три режими масштабу на карті: «Весь маршрут / Трек / Записи» | Якщо трек не покриває весь рейс (увімкнули пізно), «усе» робить лінію невидимою на відстанях 100+ км | Один fitBounds (просто, але маршрут зникає) |
| 2026-10-17 | SW тепер «мережа спочатку», кеш — лише офлайн | Раніше статика віддавалась з кешу, і після релізу користувач бачив старий код до другого оновлення | Stale-while-revalidate (швидше онлайн, але «застрялий» код) |
| 2026-10-17 | `/tiles/*` SW не перехоплює, файл кладемо в том `./tiles`, не в образ | Range-запити на 100+ МБ не коректно кешуються; redeploy інакше зітрав би файл | Плитки в образі (+100 МБ образу, зникають при redeploy) |
| 2026-10-17 | Дозволено збірку в `android/` — виняток із обмеження «без збірки». PWA лишається без збірки | Браузер не працює у фоні на смартфоні; без нативного трекера неможливе автозаписування пауз і маршруту | PWA у foreground + Wake Lock (працює лише з увімкненим екраном) |
| 2026-10-17 | Трекер — окремий APK (Foreground service), не мост до PWA: спільне API і спільна БД | PWA залишається UI; застосунок і веб — рівні клієнти, немає синхронізації між ними | WebView-обгортка (дублює застосунок), Capacitor (тягне Node/веб-збірку) |
| 2026-10-17 | Пристрії автентифікуються довгим Bearer-токеном (32 байти, хеш у БД), доступ тільки до дозволених ендпоінтів | APK не може жити на httpOnly-cookie, а пароль у застосунку — погано | Дозволити телефону лише з LAN (не працює через Cloudflare Tunnel) |
| 2026-10-17 | Одометр запитуємо в діалозі **під час зупинки** | Рішення власника: після відновлення руху водій вже їде і користуватися телефоном не може; під час зупинки він стоїть і бачить панель | Запит при відновленні руху (одометр вводився б на ходу) |
| 2026-10-17 | «Авто чи пішки» НЕ визначаємо швидкістю: під час паузи будь-який рух = ходьба, відновлення руху = >15 км/г 60 с | Зона 5–8 км/г спільна для затору й швидкої ходьби; ця модель уникає неоднозначності взагалі | Activity Recognition API (точність посередня, залежність від Play Services) |
| 2026-10-17 | Маршрут зберігаємо сегментами (`drive`/`walk`/`still`/`nosignal`) з encoded polyline, не окремими точками | 10 годин = ~1200 точок → сотні МБ/рік; сегментів ~20 і кожен з polyline | Одна таблиця точок (просто, але об'єм і батарея) |
| 2026-10-17 | Карта: локальний `region.pmtiles` (варіант C), без зовнішніх тайлів | CSP `img-src 'self'`; офлайн-доступ; жодних запитів до чужих сервісів | A — без карти; B — Leaflet + OSM (зовнішні запити, ламає CSP) |
| 2026-10-17 | GPS зберігаємо **завжди**, без терміну давності й очищення | Рішення власника: дані про місце події потрібні для розборів і суперечок із замовником навіть через роки | TTL 12 міс + автоочищення (менше даних, але втрачається доказова база) |
| 2026-10-17 | Один спільний пароль, **без користувачів, ролей і журналу «хто що зробив»** | Рішення власника: система для власного користування, водій один | Акаунти + RBAC + audit log (ускладнює і сповільнює, користі зараз нуль) |
| 2026-10-17 | `server.js` розбито на `src/` (config, logger, app, db, lib, services, routes) | 1386 рядків в одному файлі — неможливо тестувати окремі частини; `createApp()` без `listen` дає інтеграційні тести | Лишити один файл (швидше зараз, дорожче потім) |
| 2026-10-17 | Тести на вбудованому `node:test`, без Jest/Vitest | Нуль нових залежностей, працює в контейнері, швидко (~1.6 с) | Jest (звичніше, але +50 МБ і конфіг), Vitest (ESM-орієнтований, проєкт на CJS) |
| 2026-10-17 | Перед збереженням запису оновлюємо GPS, якщо фіксація старша за 5 хв (таймаут 6 с, fallback на останні відомі) | Координати з ранку брехливі ввечері; але форма не має «зависати» через GPS | Брати тільки координати з моменту відкриття застосунку (старіють), або чекати GPS без таймауту (блокує збереження) |
| 2026-10-17 | Версіонування статики через `CACHE_NAME` у Service Worker, без `?v=` у посиланнях | Один механізм замість двох; `?v=` не працював із прекешем SW | `?v=N` в index.html (треба правити в двох місцях, легко забути) |
| 2026-10-17 | Chart.js — локальна копія в `public/vendor/` | CSP `script-src 'self'`; аналітика працює офлайн; немає залежності від CDN | CDN jsdelivr + SRI (простіше, але падає без інтернету й зайвий зовнішній ризик) |
| 2026-10-17 | Звіт одним `GET /api/report` замість `1 + N` запитів | 50 рейсів = 51 запит і мегабайти JSON; тепер 3 SQL-запити | Лишити N+1 (простіше, але не масштабується) |
| 2026-10-17 | Сесії в SQLite + cookie `tt_sid` (HttpOnly, SameSite=Strict), 30 днів, ковзні | JWT у `localStorage` крадеться будь-якою XSS і не відкликається; cookie закриває обидві проблеми | JWT + refresh-токени (складніше, для одного користувача надлишково) |
| 2026-10-17 | ❌ **скасовано:** JWT (`jsonwebtoken`) для автентифікації | Замінено сесіями в SQLite; залежність видалено з `package.json` | — |
| 2026-10-17 | `trust proxy` довіряє `X-Forwarded-For` лише приватним адресам | Cloudflared приходить із приватної адреси; прямий доступ з інтернету — ні, тому підробити IP і обійти rate-limit не вийде | `trust proxy = 1` (обхід одним заголовком), `trust proxy = true` (ще гірше) |
| 2026-10-17 | CSP `script-src 'self'` без `unsafe-inline`; усі inline-обробники прибрано | Єдиний спосіб реально стримати XSS; заодно зникли рядкові `onclick` | `unsafe-inline` + екранування (XSS лишається) |
| 2026-10-17 | `better-sqlite3` (синхронний SQLite у файлі) | Один користувач, один контейнер: нуль адміністрування, миттєві запити, простий бекап файлу | PostgreSQL (потрібен окремий сервіс, бекапи, паролі) |
| 2026-10-17 | Деплой: Portainer + Cloudflare Zero Trust Tunnel, порт 8851 | Уже налаштовано власником; не чіпаємо без причини | Прямий порт + Let's Encrypt (відкриває сервер в інтернет) |
| 2026-10-17 | Пароль зберігається в `ADMIN_PASSWORD` (текст або bcrypt-хеш), без UI зміни | Один користувач; зміна = env + перезапуск контейнера | Окремий екран зміни пароля (зайвий код для одного користувача) |

## Що в роботі зараз

Код готовий, APK зібрано локально. Залишилось поза кодом: **редеплой** і **поставити APK**.

Рішення власника, деталі в `DECISIONS.md`:
- карта = **онлайн-тайли на вимогу** з дисковим кешем (v1.4.0, змінено 2026-10-18);
  локальний `region.pmtiles` — опційний офлайн-режим;
- одометр питаємо **на початку паузи** (після відновлення руху водій уже їде);
- телефони: один Android + один iPhone → трекер лише на Android;
- обмеження «без збірки» **зняте** для `android/` (PWA залишається без збірки).

**Стан інструментів для Android:** APK тепер збирається і локально — JDK 17 і Gradle 8.7
лежать у `.workbuddy-ai/build-tools/` (не в git), рецепт у [NOTES.md](NOTES.md).
CI (`Actions → Build Android APK`) лишається як другий шлях і як джерело артефакту.

## Що заблоковано і чому

| Блокер | Причина | Що потрібно |
|--------|---------|-------------|
| APK не на телефоні | Файл є, але поставити й видати токен може лише власник | Телефон + вхід у веб-застосунок |
| Бекап БД | Робиться на рівні хоста, не застосунку | Рішення власника: cron + `sqlite3 .backup` |
| Cloudflare Access | Налаштовується в Zero Trust, не в коді | Рішення власника |

## Наступні 3 кроки

1. **Редеплой** — Portainer → Stacks → `trip-tracker` → Pull and redeploy.
   Перевірити `…/api/tiles` → `{"available":true,"mode":"online"}` і відкрити будь-який
   рейс: підкладка вулиць має з'явитися сама, без жодних файлів на хості.
2. **Поставити APK** `android/app/build/outputs/apk/debug/app-debug.apk` на Android
   (якщо раніше ставили APK з CI — спершу видалити застосунок: інший debug-підпис).
   Токен — кнопка **📱 у шапці** веб-застосунку → «Підключити пристрій» → «Копіювати».
3. **Офлайн-тест + бекап** — запис у режимі польоту → мережа → рівно один запис у базі;
   далі щоденний `sqlite3 .backup` на хості з ротацією 14 днів.

## Передача (для наступної сесії)

**Де ми:** v1.4.1 запушена в `origin/main` (коміти `c15b5a2` + v1.4.1). 98 тестів зелені,
`npm run check` чистий, APK збирається локально і в CI. **Прод — на v1.3.4 і без файлу плиток:
`/api/tiles` → `available:false`, саме тому карта порожня; потрібен Pull and redeploy.**

**Що зроблено (цієї сесії):** виправлено `Unresolved reference: put` у `Polyline.kt`;
вартовий рейсу переїхав у власний потік (раніше блокував єдиний `worker` — сегменти й
«Продовження руху» не відправлялись ніколи); черга сегментів знімає і `saved`, і `skipped`;
усі звернення до черги під `segLock`; UI пристроїв (📱 → токен); підкладка карти:
`region.pmtiles` на всю Україну + виправлено додавання шарів (`vectorLayerIds()` у MapLibre
немає); **v1.4.0** — тайл-проксі на вимогу (працює для всього світу, нічого не кладемо руками).

**На чому зупинились:** код готовий і перевірений у headless Chrome (обидва режими,
темна й світла теми); далі — редеплой, телефон, реальний рейс.

**Пастки, які вже наступили (не повторювати):**
- `new URL('/tiles/{z}/{x}/{y}.mvt', origin)` кодує дужки у `%7Bz%7D` → MapLibre не
  завантажує жодного тайла. Склеюйте рядок, а не через `URL`.
- `pmtiles.getZxy()` повертає **вже розпакований** MVT (не gzip) — `Content-Encoding` не потрібен.
- `MAP.allowNetwork` читається при завантаженні `config`, тому в тестах `NODE_ENV=test`
  треба ставити **до** першого `require('../src/...')`.

**Як підняти локально:**
```bash
npm install
ADMIN_PASSWORD=test1234 PORT=3000 npm start   # http://127.0.0.1:3000
npm test && npm run check
```

**Як зібрати APK локально:** див. «Локальна збірка APK» у [NOTES.md](NOTES.md).

**Важливо:** локальний `curl` у цьому середовищі йде через проксі — для localhost
обов'язково `curl --noproxy '*'`.

## Що в роботі зараз

Код готовий, APK зібрано локально. Залишилось поза кодом: **поставити APK**, **редеплой**,
(опційно) `region.pmtiles`.

Рішення власника (2026-10-17), деталі в `DECISIONS.md`:
- карта = **C** (локальний `region.pmtiles`, без зовнішніх тайлів);
- одометр питаємо **на початку паузи** (після відновлення руху водій уже їде);
- телефони: один Android + один iPhone → трекер лише на Android;
- обмеження «без збірки» **зняте** для `android/` (PWA залишається без збірки).

**Стан інструментів для Android:** APK тепер збирається і локально — JDK 17 і Gradle 8.7
лежать у `.workbuddy-ai/build-tools/` (не в git), рецепт у [NOTES.md](NOTES.md).
CI (`Actions → Build Android APK`) лишається як другий шлях і як джерело артефакту.

## Що заблоковано і чому

| Блокер | Причина | Що потрібно |
|--------|---------|-------------|
| Підкладка карти на проді | Файл `tiles/region.pmtiles` (324 МБ) є лише локально; `/api/tiles` → `available:false` | Скопіювати на хост у `./tiles` + redeploy |
| APK не на телефоні | Файл є, але поставити й видати токен може лише власник | Телефон + вхід у веб-застосунок |
| Бекап БД | Робиться на рівні хоста, не застосунку | Рішення власника: cron + `sqlite3 .backup` |
| Cloudflare Access | Налаштовується в Zero Trust, не в коді | Рішення власника |

## Наступні 3 кроки

1. **Покласти карту на хост** — `tiles/region.pmtiles` → `<стек>/tiles/region.pmtiles`,
   далі Portainer → Stacks → `trip-tracker` → Pull and redeploy.
   Перевірити `…/api/tiles` → `{"available":true,"sizeMb":308.9}`.
2. **Поставити APK** `android/app/build/outputs/apk/debug/app-debug.apk` на Android
   (якщо раніше ставили APK з CI — спершу видалити застосунок: інший debug-підпис).
   Токен — кнопка **📱 у шапці** веб-застосунку → «Підключити пристрій» → «Копіювати».
3. **Офлайн-тест + бекап** — запис у режимі польоту → мережа → рівно один запис у базі;
   далі щоденний `sqlite3 .backup` на хості з ротацією 14 днів.

**Де ми:** v1.3.4 у робочому дереві (коміт — див. `git log -1`). 89 тестів зелені, `npm run check`
чистий, APK збирається локально і в CI. Прод оновлено до v1.3.3, але без файлу плиток:

вартовий рейсу переїхав у власний потік (раніше блокував єдиний `worker` — сегменти й

усі звернення до черги під `segLock`; UI пристроїв (📱 → токен); підкладка карти:
`region.pmtiles` на всю Україну + виправлено додавання шарів (`vectorLayerIds()` у MapLibre
немає — шари не додавались зовсім).

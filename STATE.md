**Бекенд** (`npm test` → **82/82 зелених**, `npm run check` → 36 файлів):
- `src/db/schema.js`: таблиці `devices`, `track_segments`; у `records` додано `source` і `device_id`;

**Android** (`android/`, Kotlin, без фреймворків):

  детекція зупинки (>150 м за 60 с), відновлення руху >15 км/год 60 с, батчі по 20.
- `MainActivity` — введення токена, увімкнення трекінгу, діалог «Це пауза?» з полем одометра.

## Що в роботі зараз

Нічого в коді — фаза 2 (UI маршруту) завершена й перевірена в браузері.
Залишилось поза кодом: зібрати APK, зробити редеплой, (опційно) згенерувати `region.pmtiles`.

Рішення власника (2026-10-17), деталі в `DECISIONS.md`:
- карта = **C** (локальний `region.pmtiles`, без зовнішніх тайлів);
- одометр питаємо **на початку паузи** (після відновлення руху водій уже їде);
- телефони: один Android + один iPhone → трекер лише на Android;
- обмеження «без збірки» **зняте** для `android/` (PWA залишається без збірки).

**Стан інструментів для Android:** Android SDK є (`%LOCALAPPDATA%/Android/Sdk`,
platform android-37.0, build-tools 36.0.0), але JDK лише 8, а AGP 8 потребує 17;
Gradle відсутній. Тому збірка APK — через GitHub Actions, не локально.

## Що заблоковано і чому

| Блокер | Причина | Що потрібно |
|--------|---------|-------------|
| Редеплой продакшену | Потрібна дія власника в Portainer (Pull and redeploy) | Доступ до Portainer |
| Бекап БД | Робиться на рівні хоста, не застосунку | Рішення власника: cron + `sqlite3 .backup` |
| Cloudflare Access | Налаштовується в Zero Trust, не в коді | Рішення власника |

## Наступні 3 кроки

1. **Редеплой у Portainer** → перевірити `https://trip.bojumbohost.pp.ua/api/health` і увійти заново.
2. **Перевірити офлайн-режим на реальному телефоні**: внести запис у літаку, увімкнути мережу,
   переконатися що запис з'явився рівно один раз.
3. **Налаштувати щоденний бекап** `data/database.sqlite` на хості.

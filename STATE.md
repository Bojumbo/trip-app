## Що в роботі зараз

Нічого активно не розробляється. Останній крок завершено: код у `origin/main` (4 коміти).

**Обговорюється (рішення не прийнято):** автовизначення зупинок > 2 хв під час відкритої зміни
з пропозицією записати паузу. Обмеження: браузер не працює у фоні на смартфоні, потрібна
ідентифікація пристрою (зараз її немає). Розглядається варіант окремого Android-трекера
(APK у фоні + device token, PWA лишається UI). Деталі — у TASKS.md, розділ ⚪.

**Стан інструментів для Android:** Android SDK є (`%LOCALAPPDATA%/Android/Sdk`,
platform android-37.0, build-tools 36.0.0), але JDK лише 8, а AGP 8 потребує 17;
Gradle відсутній. Тому збірка APK — через GitHub Actions, не локально.

| Блокер | Причина | Що потрібно |

## Наступні 3 кроки

1. **Редеплой у Portainer** → перевірити `https://trip.bojumbohost.pp.ua/api/health` і увійти заново.
2. **Перевірити офлайн-режим на реальному телефоні**: внести запис у літаку, увімкнути мережу,
   переконатися що запис з'явився рівно один раз.
3. **Налаштувати щоденний бекап** `data/database.sqlite` на хості.

**Як підняти локально:**
```bash
npm install
ADMIN_PASSWORD=test1234 PORT=3000 npm start   # http://127.0.0.1:3000
npm test && npm run check
```

**Важливо:** локальний `curl` у цьому середовищі йде через проксі — для localhost
обов'язково `curl --noproxy '*'`.

# Офлайн-карта регіону

Сюди кладіть `region.pmtiles` — файл підкладки карти для маршруту рейсу.
Інструкція генерації: `docs/TRACKING-MAP.md`.

- Файл **не комітиться** (`tiles/*.pmtiles` у `.gitignore`).
- У Docker теку монтується томом `./tiles:/app/public/tiles`.
- Перевірка: `curl -s <ваш-домен>/api/tiles` → `{"available":true,"sizeMb":...}`.
- Без файлу все працює: карта малює трек без підкладки вулиць.
